STORIA RACCONTATA MALE — PROTOTIPO

Per provare il gioco:
1. Estrai la cartella dal file ZIP.
2. Apri index.html con un browser moderno.

La versione include:
- 10 storie, 12 scelte per racconto
- testo completo alla fine e copia del racconto
- download del racconto in formato .txt
- pulsanti di condivisione per Facebook, X/Twitter, Tumblr, Pinterest, Instagram e Snapchat
- condivisione nativa del dispositivo, dove supportata
- link con le scelte codificate nell'indirizzo, per riaprire una storia condivisa

IMPORTANTE SULLA CONDIVISIONE:
I link pubblici funzionano quando il gioco è pubblicato su un indirizzo HTTPS, per esempio GitHub Pages. Aprendo index.html direttamente dal computer, il gioco può essere provato ma non esiste ancora un URL pubblico condivisibile.
Facebook, X, Tumblr e Pinterest aprono i rispettivi flussi di condivisione con il link della storia. Instagram e Snapchat non offrono un flusso web universale per pubblicare direttamente il testo: i pulsanti copiano il racconto e il link per incollarli nell'app.

Il download illustrato in PDF/immagine è previsto per una fase successiva, quando verranno aggiunte le illustrazioni alle scene.
